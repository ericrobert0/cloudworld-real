Novo contato

O cadastro é gravado no Chatwoot desta empresa. Os fluxos ativos recebem o contato pela API central. Não envia mensagens de WhatsApp.

Contatos no Chatwoot

Primeira página da API. Para pesquisar e administrar todo o cadastro, abra o Chatwoot nas ferramentas da empresa.

Selecione uma empresa.

Conecte as ferramentas desta empresa e escolha quais eventos devem passar de uma aplicação para outra. As credenciais ficam separadas por cliente.

Fluxos entre ferramentas

Cada fluxo encaminha os dados de um evento para uma aplicação. Cadastre e teste as conexões antes de ativar o fluxo. As alterações valem para novos eventos; entregas já na fila mantêm o destino original.

Capturar novos contatos do Chatwoot

A central consulta os contatos pela API, sem precisar abrir uma porta pública. A primeira consulta registra os contatos existentes; os próximos contatos geram eventos automaticamente. Limite de 1.500 contatos.

Chaves de integração

Use uma chave para conectar um sistema à API desta empresa. A chave aparece somente na criação. As chaves criadas aqui recebem permissão para enviar e consultar eventos.



Entregas de eventos
Entregue: destino respondeu. Pendente: aguardando tentativa. Falhou: precisa de revisão. Sem fluxo: nenhum destino estava ativo no recebimento.




O ciclo de verificação consulta as aplicações e integrações. Um container em execução não garante que a aplicação ou sua API esteja funcionando.
Adicionar verificações de rede
DNS, TCP, PING, ARPING e SNMPv3. ARPING exige Linux na mesma rede. SNMP exige um agente habilitado e credenciais próprias. Informe uma lista JSON de alvos; salvar substitui a lista anterior.

Preparação para atender clientes
Os itens pendentes precisam ser resolvidos antes da oferta comercial. Este painel não aprova automaticamente contratos, licenças, capacidade ou disponibilidade.
Alertas da operação
Falhas são abertas após duas observações consecutivas. A recuperação fica registrada. Avisos fora deste painel dependem de um destino de notificação.
Acessos ao portal do cliente
Essas contas acessam somente o portal desta empresa. Os logins e permissões dentro de cada aplicação são configurados separadamente. O editor n8n não é oferecido aos clientes neste pacote.
Ative depois de testar o login central. Contas sem vínculo e sessões por senha local serão bloqueadas.
Receber avisos fora do painel
Configure um destino HTTPS que receba JSON. Este canal é global para o administrador e recebe alertas das empresas. A ativação pode enviar os alertas abertos. Nenhum destino é habilitado por padrão.
Perfil de recursos
Backups
A cópia automática pode pausar as aplicações durante a captura para manter os dados consistentes. O destino externo e a guarda separada da chave de recuperação ainda precisam ser definidos.
